# 📊 Python for Statistics: From Rainfall to Wine Data  

This project demonstrates the use of **Python for statistical analysis** on two real-world datasets:  
- 🌧️ **Rainfall Data** – analyzing seasonal patterns, trends, and distributions.  
- 🍷 **Wine Quality Data** – studying correlations between chemical properties and wine quality scores.  

The aim is to showcase how Python simplifies **descriptive statistics, probability distributions, hypothesis testing, and data visualization** for different domains.  

---

## 🛠️ Tech Stack  
- **Python** (Pandas, NumPy, SciPy)  
- **Visualization:** Matplotlib, Seaborn  
- **Jupyter Notebook** for analysis  

---

## 📊 Workflow  
1. **Data Preprocessing** – cleaning and preparing rainfall & wine datasets.  
2. **Descriptive Statistics** – mean, median, variance, standard deviation.  
3. **Exploratory Data Analysis (EDA)** – visualizations for trends and patterns.  
4. **Hypothesis Testing** – comparing rainfall/wine features statistically.  
5. **Correlation Analysis** – finding relationships in wine quality dataset.  

---

## 📈 Results & Insights  
- Seasonal variations observed in rainfall data.  
- Strong correlations found between certain wine features and quality score.  
- Visualizations highlight how statistics reveal meaningful insights from raw data.  

---
